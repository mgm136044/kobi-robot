# lcd_face: LCD 얼굴 판 (아직 없음)

이 폴더는 **자리 표시용**입니다. 지금은 이 README 말고는 아무 파일도 없습니다.

인쇄한 얼굴 대신 LCD 화면으로 표정을 보여 주는 코비가 개발 중이며, 완성되면 이 폴더에 다음을 추가할 예정입니다. 내용과 시기는 바뀔 수 있습니다.

- LCD 얼굴 판의 URDF와 MuJoCo 모델
- 3D 프린트 파일
- 머리가 무거워진 모델에 맞춰 다시 학습한 정책(ONNX)
- 평가 결과와 시연 영상

현재 완성된 인쇄 얼굴 판의 자료는 `../printed_face/`, 정책은 `../policy/`에 있습니다. 자세한 설명은 `../README.md`의 12절을 보세요.
